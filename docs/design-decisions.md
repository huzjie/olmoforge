# 设计决策记录

## DD-001: 用「搬数据」替代「搬权重」

FSDP 的 all-gather 随总参数量增长，是万亿 MoE 训练的第一瓶颈。专家并行让
专家常驻、数据路由，通信与专家总数解耦。

## DD-002: 确定性可训练 mock 后端

为了不依赖 GPU 也能验证训练闭环，用 `md5(key)` 种子驱动 `random.Random`，
保证同一 key 永远同一结果，训练信号单调可复现。

## DD-003: 零依赖内核

张量核心只实现 MoE 层用到的算子，整个项目在裸 Python 3.9+ 可运行，审计和
部署成本最低。
